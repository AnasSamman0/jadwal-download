# Jadwal landing page

هذه صفحة ثابتة جاهزة للاستضافة على GitHub Pages أو Vercel.

## قبل النشر

1. ارفع ملف `app-release.apk` إلى GitHub Release باسم `app-release.apk`.
2. تم ضبط رابط التحميل لمستودع `AnasSamman0/jadwal-download`.
3. ارفع مجلد `website` إلى المستودع، أو اجعل `website` هو مجلد النشر في Vercel.

رابط التحميل المتوقع:

```text
https://github.com/AnasSamman0/jadwal-download/releases/latest/download/app-release.apk
```

يفضل استخدام GitHub Releases لملف APK بدل وضع الملف الثنائي داخل سورس الموقع.
